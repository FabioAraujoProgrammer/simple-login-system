# Simple Login System

A simple login system created with Python to practice programming logic and authentication concepts.

---

## Features

### login_v1
- Basic user authentication
- Username validation
- Password validation

### login_v2
- Login attempt limit
- Access blocking after failed attempts
- Remaining attempts counter

### login_v3
- User registration system
- Authentication flow
- Login attempt control

### login_v4
- Local file storage using `.txt`
- Save registered users
- Read authentication data from file
- Persistent login system
